# Nimbus — SaaS Landing Page

## Overview
- Purpose: Marketing landing page for a fictional productivity SaaS
- Target audience: Small teams and freelancers
- Vibe / mood: Minimal, modern, dark with a soft violet accent

## Tech Stack
- Framework / approach: plain HTML/CSS/JS (no build step)
- Styling: hand-written CSS with CSS variables
- Preview / dev command: open `index.html` directly, or `npx serve .`

## Pages
- `/` — sections: header, hero, features, pricing, footer
